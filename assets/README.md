# 本機空間資料

公開版本只有通用示例圖與三筆未接入設備，沒有模擬讀值。首次啟動時若沒有私人 `seed.json`，會載入 `example-seed.json`；既有資料庫不會被覆蓋。

私人 `seed.json` 可使用相同結構，放在此資料夾，並以白名單資產名稱 `floorplan.png`、`home-display.glb` 等搭配 `/assets/home/` 路徑。圖面與模型需由使用者自行提供，僅在完成驗證後開放讀取。GLB 可從「空間設定」上傳，前端會拒絕含外部資源的模型。房間與設備可在介面調整。

這裡的私人圖面、模型與真實設備盤點受 `.gitignore` 排除；憑證只能透過接入流程保存在加密資料庫，請勿放進 seed。
